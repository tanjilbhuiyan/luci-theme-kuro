# AGENTS.md

## Project Overview

**Kuro Theme** — a dark-first OpenWrt LuCI theme built with Vite 8 and Tailwind CSS v4. Licensed under Apache 2.0.

**Kuro** (黒) means black in Japanese. The design philosophy is simple: the entire LuCI interface lives in deep matte shadow while configuration content stays crisp, calm, and readable. One mode. Dark surfaces. Clear content.

Target: OpenWrt 23.05+ routers.

## Tech Stack

- **Tailwind CSS v4** — utility-first CSS with oklch color system
- **Vite 8** — build tool and dev server with custom plugins
- **pnpm** — package manager (managed via Corepack)
- **Terser** — JS minification
- **lightningcss** — CSS minification
- **Prettier** + `prettier-plugin-tailwindcss` — code formatting
- **ucode** — OpenWrt template language (`.ut` files)

## Development Commands

All commands run from the `frontend/` directory:

```bash
cd frontend/
pnpm install          # Install dependencies
pnpm dev              # Start dev server (proxies to OpenWrt router)
pnpm build            # Production build → htdocs/luci-static/
pnpm clean            # Clean build output
```

### Environment Setup

Copy `frontend/.env.example` to `frontend/.env` and set `VITE_OPENWRT_HOST` to your router's address (e.g., `http://192.168.1.1`).

### Testing the Theme

**Method 1: Dev Server (recommended for CSS/JS changes)**

⚠️ **The dev server proxies page requests to your router but intercepts CSS/JS to serve local files. This only works if the router already has the kuro theme templates installed.** If kuro is not on the router, the router will generate HTML referencing the old theme's CSS paths, and your local dev server won't intercept anything.

**One-time setup on router:**

```bash
cd frontend && pnpm build

# Copy templates to router
sftp root@192.168.1.1 <<'SFTP'
mkdir /usr/share/ucode/luci/template/themes/kuro
put ../ucode/template/themes/kuro/header.ut /usr/share/ucode/luci/template/themes/kuro/header.ut
put ../ucode/template/themes/kuro/footer.ut /usr/share/ucode/luci/template/themes/kuro/footer.ut
put ../ucode/template/themes/kuro/sysauth.ut /usr/share/ucode/luci/template/themes/kuro/sysauth.ut
SFTP

# Copy built assets to router
sftp root@192.168.1.1 <<'SFTP'
mkdir /www/luci-static/kuro
mkdir /www/luci-static/resources
put ../htdocs/luci-static/kuro/main.css /www/luci-static/kuro/main.css
put -r ../htdocs/luci-static/kuro/fonts /www/luci-static/kuro/
put -r ../htdocs/luci-static/kuro/images /www/luci-static/kuro/
put ../htdocs/luci-static/resources/menu-kuro.js /www/luci-static/resources/menu-kuro.js
SFTP

# Activate theme and restart
ssh root@192.168.1.1 "uci set luci.themes.Kuro=/luci-static/kuro && uci set luci.main.mediaurlbase=/luci-static/kuro && uci commit luci && /etc/init.d/uhttpd restart"
```

**Daily workflow after setup:**

1. Set `VITE_OPENWRT_HOST=http://YOUR_ROUTER_IP` in `frontend/.env`.
2. Run `pnpm dev` — the Vite server starts at `http://127.0.0.1:5173`.
3. Open **`http://localhost:5173/cgi-bin/luci`** (your local dev server, NOT the router directly).
4. CSS and JS changes trigger full page reload automatically.

**How it works:**

```
Browser → localhost:5173
    ├── /luci-static/kuro/main.css  →  YOUR LOCAL frontend/src/media/main.css  (live!)
    ├── /luci-static/resources/...  →  YOUR LOCAL frontend/src/resource/...    (live!)
    ├── /luci-static/kuro/fonts/... →  YOUR LOCAL frontend/public/kuro/...     (live!)
    └── /cgi-bin/luci/...           →  ROUTER 192.168.1.1 (HTML + data)
```

The router handles page logic and data. Your PC handles CSS/JS with live reload.

**Method 2: Template Changes (requires router deployment)**

Ucode templates (`.ut` files) are compiled and cached by uhttpd. After any `.ut` change:

```bash
# Upload templates to router
sftp root@YOUR_ROUTER_IP <<'SFTP'
put ucode/template/themes/kuro/header.ut /usr/share/ucode/luci/template/themes/kuro/header.ut
put ucode/template/themes/kuro/footer.ut /usr/share/ucode/luci/template/themes/kuro/footer.ut
put ucode/template/themes/kuro/sysauth.ut /usr/share/ucode/luci/template/themes/kuro/sysauth.ut
SFTP

# Restart uhttpd to flush template cache
# IMPORTANT: Use MSYS_NO_PATHCONV=1 on Windows (Git Bash)
MSYS_NO_PATHCONV=1 ssh root@YOUR_ROUTER_IP "/etc/init.d/uhttpd restart"
```

**Method 3: Full Package Build & Install**

For a complete test including all assets:

```bash
# 1. Build frontend assets
cd frontend/ && pnpm build

# 2. Build OpenWrt package (requires OpenWrt SDK or buildroot)
# Or use the GitHub Actions workflow to build .ipk/.apk

# 3. Install on router
cd /tmp
# For opkg (OpenWrt < 25.12):
opkg install luci-theme-kuro_1.0.4-r20260604_all.ipk
# For apk (OpenWrt 25.12+):
apk add --allow-untrusted luci-theme-kuro-1.0.4-r20260604.apk
```

## Build Pipeline

1. Vite builds CSS entry (`src/media/main.css`) with Tailwind CSS
2. PostCSS plugin removes `@layer` at-rules (OpenWrt compatibility)
3. CSS minified via lightningcss
4. Custom `kuro-js-compress` Vite plugin minifies JS via Terser
5. Static assets copied from `frontend/public/kuro/`
6. Output lands in `htdocs/luci-static/`

## Design System

### Philosophy

- **Dark surfaces, readable content** — no mode switching. The shell and content are dark, with enough contrast for dense configuration pages.
- **Depth through restraint** — subtle header separation, quiet active states, and minimal shadows
- **One mode to rule them all** — Kuro is dark. Content is visible. That's it.

### Color Palette

**Dark Chrome (`:root`)**:
- Background: `#0a0a0a` — matte near-black
- Foreground: `#d4d4d4` — soft gray
- Primary: `#7a9ec8` — muted steel blue
- Border: `#1e1e1e` — subtle separators
- Muted: `#161616` — elevated dark surfaces

**Dark Content (`.docs-content`)**:
- Background: `#111111` — quiet charcoal panel
- Foreground: `#d4d4d4` — readable soft gray
- Border: `#262626` — visible but restrained separators
- Muted: `#1a1a1a` — nested controls and secondary surfaces

### Typography

- **Aeonik Pro** (500) — UI body text, headings, brand
- **Geist Mono** (400/500) — code, terminal, inputs

### Key Features

- Frosted glass header that becomes opaque on scroll
- Collapsible sidebar with animated chevrons
- Table of Contents with scroll-spy
- Floating toast notifications with spring physics
- Vercel-style animated tab underlines
- WebGL2 dot-grid background on login page
- Pill toggle switches for boolean checkboxes
- Custom accessible dropdowns replacing native selects
- View Transitions API for page transitions

## CI/CD Workflows

- **build-and-commit.yml** — On push to `master` (when `frontend/` sources change), auto-builds and commits `htdocs/` output. Commit messages prefixed with `build:` are skipped.
- **pr-check.yml** — On PRs to `master`/`main`, runs Prettier check and build verification.
- **build-and-release-kuro.yml** — On `v*` tags or manual trigger, compiles OpenWrt `.ipk`/`.apk` packages.

## Important Notes

- **JS files are NOT bundled** — they're individually minified and placed at the same relative paths under `resources/`.
- **`htdocs/` is auto-generated** — don't manually edit files there. Edit sources in `frontend/src/` and run `pnpm build`.
- **Template changes** (`.ut` files) have no hot reload — deploy to router and restart uhttpd.
- **The `@layer` removal PostCSS plugin is critical** — OpenWrt's LuCI doesn't support CSS layers.
- **Browser targets**: Chrome 111+, Safari 16.4+, Firefox 128+.

## Windows (Git Bash / MSYS2) Caveats

- **Path conversion**: MSYS auto-converts Unix paths in SSH commands. Always prefix SSH commands with `MSYS_NO_PATHCONV=1`.
- **SSH host key**: If the router is reflashed, remove the old key with `ssh-keygen -R ROUTER_IP`.
